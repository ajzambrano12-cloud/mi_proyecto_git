Fundamentos de Sistemas Web - Control de Versiones con Git

Universidad de las Fuerzas Armadas ESPE | NRC 36750

Bienvenido al proyecto mi_proyecto_git

Este proyecto web forma parte de la Actividad de Aprendizaje #3 de la asignatura Fundamentos de Sistemas Web (Periodo Septiembre 2026 - Febrero 2027). Su objetivo es aplicar el flujo de trabajo completo de Git y GitHub mediante el versionamiento incremental de código fuente HTML5 y CSS.

Objetivos de la Práctica

Configurar la identidad global del desarrollador en Git, inicializar un repositorio local, registrar commits descriptivos y sincronizar los cambios hacia un repositorio remoto público alojado en GitHub.
